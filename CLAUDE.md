# foreign_press_agent

Периодический сервис-мониторинг зарубежной (не РФ) **спортивной** прессы для контент-портала «Лиги Ставок». Каждый час собирает дайджест международных спортивных материалов (разборы/аналитика, трансферы, заявления, рекорды, скандалы, слухи, травмы, наши за рубежом) и постит его в takopi-тред «Foreign Press Agent» (thread_id=4179). Язык — русский.

**Два раздела (модель контента).** И дайджест, и публичный сайт разбиты на две ленты: **Новости** (оперативная лента в стиле информагентства — заголовок + подзаголовок + ссылка, БЕЗ буллитов; сюда же вливаются результаты/рекорды-статистика с тегом `records`, а также слухи `rumors` и заявления `statements` — они оперативные факты, поэтому всегда в новостях) и **Аналитика** (крупные авторские разборы, ИИ выжимает суть буллит-поинтами — только тут). Навигация на сайте — по **странам/лигам** (Англия, Франция, Испания, Италия, Германия, Португалия, Турция, Нидерланды, еврокубки), а жанровые теги (`CATEGORIES`: матч/трансфер/рекорд/скандал…) остаются «под капотом» как внутренний ориентир агента и мелкий маркер на карточке. Дедуп по сюжету: одна история — одна карточка, самый ранний источник основной, остальные уходят в `related` ссылками. Бейдж «🇷🇺 Уже в РФ» (поля `ru_covered`/`ru_source`): агент через WebSearch проверяет, освещён ли сюжет российскими спорт-СМИ (sports.ru, championat.com, sport-express.ru и др.) — редакции видно, что это уже не эксклюзив. Приоритет — футбол (расширяемо). Разделы задаются `SECTIONS`, темы — `CATEGORIES`, страны — `COUNTRIES` в `scripts/run.py`, продублированы в `web/app.js`.

⚠️ **Фокус — спорт, не iGaming/беттинг.** Раньше агент мониторил беттинг-индустрию; по брифу редакции переключён на спортивный контент (события, персоны, турниры). Источники заданы двумя слоями в `PROMPT` (`scripts/run.py`): **первый слой — широкая воронка** (~50 изданий, сгруппированы по опорным странам: Англия, Франция, Испания, Италия, Германия, Португалия, Турция, Нидерланды + еврокубки) — обязательный обход для НОВОСТЕЙ и база для аналитики; **второй слой — узкое горлышко ТОЛЬКО для аналитики** (~25 прямых директорий: авторские колонки, тактические/статистические рубрики — напр. L'Equipe Analyse tactique, Gazzetta Numbers, F365 16 Conclusions, The Analyst/Opta) — отсюда агент берёт крупные разборы и статистические тренды. Список «наших за рубежом» (именной ростер игроков/клубов для тега `russians`) и темы тоже в `PROMPT`. Список источников/ростер и модель контента (две ленты, навигация по странам, новости плоские, чаще обновление) согласованы с редакцией (Костя, встреча 2026-09-17).

## Как работает
- `scripts/run.py` запускается launchd-агентом `com.foreign-press-agent` (каждый час: 00/01/…/23 local, `StartCalendarInterval` массивом).
- Внутри вызывает headless Claude (`claude -p`, модель из `FPA_MODEL`, инструменты только `WebSearch`/`WebFetch`) — использует подписку Claude Code, **без сторонних API-ключей**.
- Результат постит в Telegram-тред через Bot API. Логи — `logs/out.log`, `logs/err.log`.

## Секреты
- Своих секретов у проекта нет. Telegram `bot_token` + `chat_id` читаются в рантайме из `~/.takopi/takopi.toml`.
- `.env` (chmod 600, gitignored) — только несекретный конфиг: `FPA_THREAD_ID`, `FPA_MODEL`.

## Наружу не экспонируется
Это periodic job, не сервер: порт не занимает, ingress/туннели не трогает.

## Допущения (можно менять одним сообщением)
Функциональный спек не был задан явно — восстановлен по названию агента. Текущие дефолты:
- **Что мониторим:** зарубежная спортивная пресса — авторские разборы/аналитика, расклады перед матчами, трансферы, заявления, рекорды, скандалы, слухи, травмы, российские игроки/тренеры за рубежом. Промпт и список источников — в `scripts/run.py` (`PROMPT`).
- **Свежесть:** берём только материалы не старше 2 часов (`MAX_AGE_HOURS`, окно ≈2× интервала запуска). Агент возвращает `published_at` (ISO 8601), а `filter_fresh()` в `run.py` жёстко отбрасывает всё старше 2 ч и материалы без проверяемого времени публикации. Дедуп между запусками: в Telegram и на сайт уходят ТОЛЬКО материалы, которых ещё нет в архиве (`merge_web_data` возвращает новые айтемы) — при пересечении 2-часовых окон одна и та же статья не постится повторно и не плодит пустые коммиты. Лента (архив и сайт) сортируется по времени публикации (`published_at`, новейшее сверху). Если свежего/нового нет — тихо выходим (без сообщений в тред, чтобы не спамить при частом запуске).
- **Куда:** takopi-тред «Foreign Press Agent» (4179). Внутренний канал, не публикация наружу.
- **Как часто:** каждый час (00/01/…/23 local). Меняется в plist (`StartCalendarInterval` массивом).
- **Движок:** headless Claude Code (подписка), без доп. затрат на API.

Чтобы скорректировать тему/частоту/адресата — скажи, поправлю `PROMPT`, `.env`, plist.

## Управление
```
launchctl list | grep foreign-press-agent          # PID/exit
tail -20 ~/foreign_press_agent/logs/err.log
python3 ~/foreign_press_agent/scripts/run.py        # ручной прогон
launchctl kickstart -k gui/501/com.foreign-press-agent   # форс-запуск
```
